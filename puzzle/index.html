The Dessert Vault

A free, complete printable escape room for two — three puzzles, one printed page, about 20 minutes. No app, no signup, no timer. Print this page, sit down together, and solve it in order.

This is the whole game — nothing is locked behind a purchase. Looking for a longer, 60–90 minute evening instead? See the full printable kit.

The setup: Somewhere in the house is a "vault" — a drawer, a box, or an envelope — worth opening tonight. Maybe there's dessert in it. Maybe it's empty and the fun was the puzzles. Solve the three cards below, in order, to find the vault's 3-digit code.

Puzzle One — Which Course?

On tonight's menu, the appetizer is served first and the main course is served third. Soup is served somewhere between the appetizer and the main course. Dessert is served fourth.

What number course is the soup?

Puzzle Two — The Cipher

Someone left a note in a simple code: every letter is written as the letter that comes one step after it in the alphabet. So a real A was written as B, a real B was written as C, and so on.

D B O E M F

Shift each letter back by one to decode the word, then count how many letters are in it.

Puzzle Three — Setting the Table

You're setting a table for two: 2 plates, 2 forks, and 1 candle in the middle.

Add up the plates, the forks, and the candle. Take the last digit of that total.

The Vault

Put your three digits together in order — that's the code. Say it out loud, then go open whatever you decided the "vault" was tonight.

Optional: before you start, write the real code on a sticky note, tape it inside a drawer with a small treat, and don't peek until you've solved all three.

Answer key (no peeking until you're stuck)

Puzzle One: Appetizer = 1st, soup = 2nd, main course = 3rd, dessert = 4th. Answer: 2.

Puzzle Two: Shifting D-B-O-E-M-F back one letter each gives C-A-N-D-L-E — "CANDLE," six letters. Answer: 6.

Puzzle Three: 2 + 2 + 1 = 5. Last digit: 5.

Vault code: 2-6-5.
